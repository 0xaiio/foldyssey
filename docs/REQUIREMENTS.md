# 需求与验收（REQUIREMENTS）

优先级沿用提示词：**P0** = 保护可发布核心（Gate A），**P1** = 目标完整版本（Gate B），
**P2** = 资源允许时的增强（Gate C）。状态定义见 `TASKS.md`。

## 用户故事

| ID | 故事 | 验收 |
|---|---|---|
| US-1 | 作为第一次来的访客，我想不读教程就开始玩 | 首页主按钮直达关卡，进入后 10 秒内可理解"折→剪→展" |
| US-2 | 作为玩家，我想看到自己这一刀的真实结果 | 改变参数后图案随之变化；评分来自几何集合而非截图 |
| US-3 | 作为玩家，我想知道差在哪里 | 提供目标轮廓 + 多剪/少剪差异覆盖 + 可解释文案 |
| US-4 | 作为创作者，我想做自己的对称剪纸并带走 | 工坊可编辑、可保存、可导出 SVG/PNG，导出可离线打开 |
| US-5 | 作为怀疑者，我想知道它是不是"假动画" | About 页写清模型、边界、未实现项与免责 |

## 范围之外（明确不做）

- 任意曲线切口、任意斜折、自动求解任意目标图案。
- 纸张物理仿真（弯曲/厚度/碰撞）。
- 用户账号、云端同步、多人协作。
- 经核验的可打印实体模板（`manufacturability` 不会写成 `verified`）。

## 验收口径

1. 所有"已完成"项必须有可执行证据（测试用例名、截图、命令输出）。
2. 几何相关结论以 `src/tests/geometry.test.ts` 的断言为准，不以肉眼观感为准。
3. 线上结论以 `submission/publish_verification.md` 的记录为准，不以本地预览为准。
