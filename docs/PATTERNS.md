# 图案档案（PATTERNS）

> 阶段 4「典藏纹样」5 个图案 + 阶段 5「让刀转弯」5 个图案（含曲线）+ 原有 6 关，共 16 个。
> 曲线剪的模型、误差界与分级判据见 `docs/SCISSOR_CURVES.md`。
> 每个图案都给出**折叠结构 / 切割逻辑 / 展开效果**，参数全部由本项目引擎正向构造：
> 目标区域 = 把标准解喂进 `applyCuts()` 得到的纸形，不是画出来的图。
>
> **关于 Demaine 等人研究的引用边界**：Erik D. Demaine、Martin L. Demaine 与 Anna Lubiw 的
> fold-and-cut 定理断言：任意一族直线段，都**存在**一种平折，使一刀直线切割得到它们
> （Theorem 1，LNCS 1763，2000；原文与译文见「纸艺中的数学」第 5 张卡片）。
> 关键词是"存在"——定理不保证任意折法都行，也不保证少数几次对折就够。
> 本项目的折叠集合固定为 5 种预设（不折 / 竖折 / 横折 / 正交双折 / 八折），因此**无法**复刻
> 五角星、字母、任意多边形等需要非 45° 折痕的图案。本文引用的只是公开的数学结论，
> **没有使用任何 Demaine 等人的图片、谜题文件、字体或源码**；所有参数都是自行推导的。

## 1. 八方连珠 `pearls` · 阶段 4

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4）：竖折 → 横折 → 对角折，正方形折成 45° 楔形 |
| 刀数 | 5（1 直线 + 1 折剪 + 3 镂空） |
| 目标面积 | 3.55 / 4（保留 89%） |

**折叠结构**：8 个 45° 扇区在 D4 的 8 个元素下映到同一片纸包，所以纸包里的一刀，
展开后必然出现 8 份。

**切割逻辑**

1. 直线·负侧 0.24 —— 八边形花心。8 条边来自 8 个扇区的同一条直线。
2. 折剪，顶点 0.46、张口 0.16 —— 从边缘剪入 8 道细缝，缝间留下花瓣。
3. 圆孔 r 0.60 —— 一圈 8 个小圆，压在花瓣根部。
4. 叶孔 r 0.74、长宽比 2.4、竖放 —— 一圈柳叶，位于花瓣中部。
5. 菱孔 r 0.90 —— 花瓣尖端收一枚小菱形。

**展开效果**：三层同心的"连珠"——八边形花心 → 八道细缝 → 圆、叶、菱三圈珠链，
每圈 8 个。同一条半径上排着三种孔，是三条独立镂空刀叠加的结果。

**研究灵感**：连珠纹是中国剪纸与织锦的常见骨架（圆点成串、层层相套），本项目自行构造参数。

## 2. 藻井 `caisson` · 阶段 4

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 6（2 直线 + 1 折剪 + 3 镂空） |
| 目标面积 | 3.16 / 4（保留 79%） |

**折叠结构**：八折；两圈菱形分别取 22.5° 与 0° 两个不同轨道，展开后自然错开 45°。

**切割逻辑**

1. 直线·负侧 0.30 —— 八边形花心。
2. 折剪 0.52 / 0.24 —— 八片主瓣。
3. 菱孔 45° / r 0.68 —— 斜向一圈 8 枚菱形。
4. 菱孔 0° / r 0.68 —— 轴向一圈 8 枚菱形，与上一圈错开 45°。
5. 圆孔 r 0.88 —— 外圈 8 个圆点。
6. 直线·正侧 1.20 —— 削掉纸包远端，把外缘收成正八边形。

**展开效果**：花心 + 八瓣 + 两圈错开的菱形 + 圆点 + 八边形外框，共 12 个孔洞、40 段轮廓。
同心层叠的关键是**半径互不重叠**：每刀占一个半径带，六刀叠加仍是干净结构。

**研究灵感**：藻井是中国古建筑天花板的层层内收结构；只借用"同心内收"的几何骨架。

## 3. 菱窗 `diamond-window` · 阶段 4

| 项 | 内容 |
|---|---|
| 折法 | 正交双折（D2，四重镜像） |
| 刀数 | 5（3 直线 + 2 镂空） |
| 目标面积 | 1.69 / 4（保留 42%） |

**折叠结构**：竖折 → 横折，四层叠在第一象限；4 个象限用 (±x, ±y) 映到同一片纸包。
对称群是 D2 而不是 D4，所以中心孔是菱形而不是八边形。

**切割逻辑**

1. 直线 45°/0.42 负侧 —— 中心大菱形孔。
2. 直线 0°/0.78 正侧 —— 削去左右外缘。
3. 直线 90°/0.78 正侧 —— 削去上下外缘，与上一刀合力把外框收成八边形。
4. 菱孔 45°/0.78 —— 四角小菱形。
5. 圆孔 0°/0.62 —— 两侧圆点。

**展开效果**：八边形外框 + 中央大菱形 + 四角小菱形 + 两侧圆点；
5 条切口各被复制 4 份。两条互相垂直的"正侧"直线干了一件"轮廓"的活。

**研究灵感**：菱花窗格是江南民居木窗的常见格心；把窗格翻译成折叠与切割，不使用任何照片或图样。

## 4. 六出 `sixfold` · 阶段 4

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4）—— **近似**六重 |
| 刀数 | 5（1 直线 + 2 折剪 + 2 镂空） |
| 目标面积 | 3.36 / 4（保留 84%） |

**折叠结构**：八折。雪花天然是六重对称（60°），而正方形只能折出 8 重（45°），
两者不能整除——本关因此明确标注为"近似"，标题与说明都不声称六角。

**切割逻辑**

1. 直线 0.24 —— 小花心。
2. 折剪 22.5°/0.30/0.16 —— 8 条深主枝。
3. 折剪 40°/0.56/0.12 —— 斜向剪侧枝。**离折痕只有 5°，但不压在折痕上**：
   压上去会让齿形退化，布尔运算会失败（这是实测踩到的坑）。
4. 叶孔 0.46、长宽比 2.8 —— 主枝上的细长叶。
5. 圆孔 0.80 —— 枝端圆点。

**展开效果**：8 条主枝 + 每条末端的 Y 形分叉 + 枝上细叶 + 枝端圆点。
剪在折痕附近的缺口会被两侧的纸各复制一次，于是自然形成对称的分叉——不需要画"Y"。

**研究灵感**：Erik D. Demaine、Martin L. Demaine 与 Anna Lubiw 的 fold-and-cut 定理说明
"任意一族直线段都存在某种平折、可一刀剪出"。本关受 5 种固定折法限制，只做八折近似，
不声称复刻六角雪花；未使用其任何图片或代码。

## 5. 重瓣 `double-petal` · 阶段 4

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 5（1 直线 + 2 折剪 + 2 镂空） |
| 目标面积 | 3.24 / 4（保留 81%） |

**折叠结构**：八折。两刀同在 45° 楔形内，方位相差 22.5°（22.5° 与 0°），
展开后每片花瓣两侧各有一道肩线。

**切割逻辑**

1. 直线·负侧 0.30 —— 八边形花心。
2. 折剪 22.5°/0.52/0.18 —— 主轴上的深缝，决定内瓣长度。
3. 折剪 0°/0.50/0.16 —— 错开 22.5° 的浅缝，决定外肩宽度。
4. 圆孔 0.74 —— 瓣面上一圈小圆。
5. 菱孔 0.92 —— 瓣尖一枚菱形。

**展开效果**：8 片双层花瓣——内瓣细长、外肩宽阔，两者错开半个方位；瓣上缀圆点、瓣尖收菱形。
两刀错位叠加时，先剪的一刀定内轮廓，后剪的一刀在外侧加宽，层次就是这么来的，不需要曲线。

**研究灵感**：重瓣是传统团花常见的层次处理（花瓣分内外两层），构造由本项目自行推导。

## 6. 玉环 `ring` · 阶段 2（剪刀能力：两刀）

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 2（2 直线） |
| 目标面积 | 2.98 / 4（保留 74%） |

**折叠结构**：两条切口都取 22.5°，与纸包楔形的角平分线重合，所以内外边界都是**正八边形**。

**切割逻辑**

1. 直线·负侧 0.50 —— 削去靠近中心的一侧，留下八边形孔。
2. 直线·正侧 1.15 —— 削去纸包远端，把外缘收成正八边形。

**展开效果**：内八边形孔 + 外八边形边，构成一枚等宽的八角环；环宽 = 两条线到中心的距离之差
（1.15 − 0.50 = 0.65）。两刀各被复制 8 份。

**研究灵感**：玉环是中国玉器与窗棂的常见母题（内外同心的八角/圆环），此处只借用骨架。

## 7. 波边 `scallop` · 阶段 5（剪刀能力：曲线 / 弧线）

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 1（1 条曲线，`bends = 1`） |
| 目标面积 | 3.01 / 4（保留 75%） |

**折叠结构**：曲线在纸包自身的切向跨度内定义（"1 段弧"跨满手里的纸），八折复制成 8 道扇贝。

**切割逻辑**：法线 0°、距中心 0.99、弯曲 −0.18、1 段弧、剪法向正侧。刀贴着纸包外缘走，
中段向内凹 0.18，两端回到弦上——**两端落在折痕上**，所以 8 份扇贝首尾相接，边是连续的。

**展开效果**：四边各两道浅弧、八角收尖的方胜形；边界 89% 为平滑曲边。

**研究灵感**：扇贝/连弧边（灯花、窗裙的波浪缘）。参数由引擎正向推导，未使用任何图样文件。

## 8. 旋风 `swirl` · 阶段 5（剪刀能力：曲线 / S 形）

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 1（1 条曲线，`bends = 2`） |
| 目标面积 | 2.38 / 4（保留 60%） |

**折叠结构**：法线取 67.5°，斜跨纸包；相邻扇区互为镜像，于是每条臂的弯**方向相反**，
整体读起来像风车。

**切割逻辑**：法线 67.5°、距中心 0.66、弯曲 −0.16、S 形、剪法向正侧。S 形有一个拐点，
拐点两侧曲率变号，切开的边界因此既有凸也有凹。

**展开效果**：四臂风车，每臂外侧外凸、内侧内凹，转角收尖；边界 65% 为曲边。

**研究灵感**：旋子纹/风车纹的动势。只用「一次拐弯」这一刀法重新构造。

## 9. 葫芦 `jar` · 阶段 5（剪刀能力：曲线 / 波浪）

| 项 | 内容 |
|---|---|
| 折法 | 竖折（2 层） |
| 刀数 | 1（1 条曲线，`bends = 3`） |
| 目标面积 | 2.00 / 4（保留 50%） |

**折叠结构**：左半张翻到右半张上，两层叠在 `x ∈ [0,1]`。一刀同时作用在两层纸上，
轮廓因此左右完全对称。

**切割逻辑**：法线 0°、距中心 0.45、弯曲 0.24、3 个半波、剪法向正侧。三个半波 = 两个拐点，
轮廓先收（颈）、再放（腹）、再收（腰）。

**展开效果**：左右对称的葫芦剪影，轮廓 68% 为曲边。**整张纸就是成品，没有内孔**——
这是「剪影」的做法，也是本作唯一一个靠曲线定义外轮廓的关卡。

**研究灵感**：葫芦（福禄）是剪纸最常见的剪影题材之一。

## 10. 花窗 `lattice` · 阶段 5（剪刀能力：曲线 + 两刀）

| 项 | 内容 |
|---|---|
| 折法 | 八折（D4） |
| 刀数 | 2（1 曲线 + 1 直线） |
| 目标面积 | 2.80 / 4（保留 70%） |

**折叠结构**：两刀各占一个半径带——外带是曲线，内带是直线，互不侵占。

**切割逻辑**

1. 曲线 0° / 1.00 / −0.16 / 1 段弧 —— 八道扇贝，压在纸包最外侧。
2. 直线 22.5° / 0.34 / 负侧 —— 正八边形花心。

**展开效果**：扇贝外缘 + 八边形花心的窗式构图；外缘 69% 为曲边，内孔是纯直线。
曲率不改变复制方式：曲线照样被 D4 复制八份，所以「柔边 + 硬心」可以共存。

**研究灵感**：「软边硬心」是江南窗棂与团花常见的对比手法。

## 11. 参数为什么会"敏感"：三个实测结论

这三条都是开发过程中量出来的，写进档案以免后人重蹈：

| 结论 | 数据 |
|---|---|
| 一刀压在两片纸的折痕上，展开会得到对称分叉 | 六出关第 3 刀从 45° 改到 40°，单步容差从 93.6% 回到 97.2% |
| 浅齿必须宽、深齿必然窄（旧缺口模型的限制） | 齿深 0.08 想要 0.08 开口需要 width=1.4，超出上限；因此锯齿改用"边缘菱形孔" |
| 多条切口叠加时，半径要分层 | 藻井六刀各占一个半径带；若挤在同一带，展开会糊成一团 |

对应的几何鲁棒性修复（`differenceMP` / `unionMP` 的增量回退、IoU 的面积恒等式兜底）
记录在 `docs/GEOMETRY_SPEC.md` 与 `TEST_REPORT.md`。
