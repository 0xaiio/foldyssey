# 几何规格（GEOMETRY_SPEC）

本文是实现与验收的**唯一几何契约**。修改 `src/geometry/` 时必须同步本文与
`src/tests/geometry.test.ts`。

---

## 1. 坐标与单位

| 名称 | 定义 |
|---|---|
| 纸张坐标（paper） | 初始纸是 `P = [-1,1] × [-1,1]`，即边长 `a = 1`，面积 `4` |
| 纸包坐标（packet） | 折叠后所有层叠在一起的区域，由预设给出（见 §3） |
| SVG 坐标 | `viewBox` 由相机给出，绘制组带 `transform="scale(1,-1)"`，因此**数学 y 向上、SVG y 向下** |
| 角度 | 法向量极角，单位度，取值 `[0, 180)`（`n` 与 `-n` 加翻面等价） |
| 长度 | 与纸张边长同单位（`a = 1`），无物理单位 |

布尔运算的容差：面积小于 `1e-9` 的碎片被丢弃；坐标保留 5 位小数输出到 SVG。
`polygon-clipping` 的输入输出没有显式容差，退化多边形由 `cleanRing` 去重处理。

---

## 2. 纸张模型

初始纸被划分为若干**片区** `Pᵢ`（互不重叠、并集为 `P`）。每个片区带一个仿射等距变换

```
fᵢ(x) = Rᵢ x + tᵢ ,   Rᵢᵀ Rᵢ = I
```

把 `Pᵢ` 映到纸包，并记录其逆 `fᵢ⁻¹`。实现的四个预设中所有 `Rᵢ` 都是对角符号矩阵
（`diag(±1, ±1)`），`tᵢ = 0`，因此 `fᵢ = fᵢ⁻¹`。

片区还记录：`layer`（绘制/层序）、`flips`（在哪条轴上被镜像，用于折叠动画）。

> **关键区别**：二维几何决定最终形状；动画只描述过程。`PaperStage` 不构造第二套结果状态。

## 3. 折叠预设

| id | 纸包 packet | 片区数 | 变换 | 对称 |
|---|---|---|---|---|
| `none` | `[-1,1]²` | 1 | 恒等 | 无 |
| `vertical` | `[0,1] × [-1,1]` | 2 | 右半恒等；左半 `(x,y)↦(−x,y)` | 关于 `x=0` 镜像 |
| `horizontal` | `[-1,1] × [0,1]` | 2 | 上半恒等；下半 `(x,y)↦(x,−y)` | 关于 `y=0` 镜像 |
| `orthogonal2` | `[0,1]²` | 4 | 四个象限分别用 `(±x, ±y)` 映到第一象限 | 四重镜像（D2） |
| `radial8` | 45° 楔形 `{0 ≤ v ≤ u ≤ 1}` | 8 | 8 个 45° 扇区用 D4 的 8 个元素映到楔形 | 八重镜像（D4） |

`radial8` 是传统窗花的折法：竖折 → 横折 → 沿对角线折成尖角。三个折痕把正方形分成 8 个
45° 扇区，每一片用一个 D4 元素（4 个旋转 + 4 个反射）映到楔形纸包：

| 扇区 | 角度 | forward | 折序（history） |
|---|---|---|---|
| s0 | 0°–45° | 恒等 | — |
| s1 | 45°–90° | 关于 `y=x` 反射 | d |
| s2 | 90°–135° | 旋转 270° | v → d |
| s3 | 135°–180° | `(x,y)↦(−x,y)` | v |
| s4 | 180°–225° | `(x,y)↦(−x,−y)` | v → h |
| s5 | 225°–270° | 关于 `y=−x` 反射 | v → h → d |
| s6 | 270°–315° | 旋转 90° | h → d |
| s7 | 315°–360° | `(x,y)↦(x,−y)` | h |

**不变量**：把 8 个扇区并起来必须恰好铺满正方形（面积 = 4，有测试）；折叠动画在
`foldedness = 1` 时算出的矩阵必须逐元素等于该片的 `forward`（有测试）。

`orthogonal2` 的四片区：

| 片区 | 区域 | forward / inverse |
|---|---|---|
| q1 | `[0,1]×[0,1]` | 恒等 |
| q2 | `[-1,0]×[0,1]` | `(−x, y)` |
| q3 | `[-1,-1]×[0,0]` | `(−x, −y)` |
| q4 | `[0,-1]×[1,0]` | `(x, −y)` |

折叠动画把每个被镜像的轴表示为缩放 `+1 → −1`（经过 0），端点精确、中间帧是
**二维步骤化示意**，见 `patchRenderMatrix()`。`orthogonal2` 的两步在时间上重叠
（`t ∈ [0,0.55]` 竖折，`t ∈ [0.45,1]` 横折）。

## 4. 切割语义

四种原语：**直线**（4）、**折剪**（4.1）、**镂空**（4.2）、**曲线**（4.4）；
锯齿（4.3）不是新原语，而是沿纸包边缘排的一串菱形孔。四种都是物理上可以用剪刀完成的动作，
每一种都保留「移除的是有面积的区域，不是零宽度的线」这条底线。

先看直线，它是另外三种的语义基准。

一条切割由 `{n, offset, removedSide}` 给出，`|n| = 1`：

```
removedSide = 'negative'  →  移除  { p : n·p < offset }
removedSide = 'positive'  →  移除  { p : n·p > offset }
```

**被移除的是半平面（有面积），不是零宽度的线。** 实现步骤：

1. 用 Sutherland–Hodgman 把足够大的矩形裁到目标半平面，得到 `H`；
2. `D = packet ∩ H`（纸包坐标）；
3. 对每个片区：`holeᵢ = fᵢ⁻¹(D)`，`regionᵢ ← regionᵢ \ holeᵢ`；
4. 展开结果 `S = ⋃ᵢ regionᵢ`。

因此**每一层都被独立剪一次**，不存在"只剪一遍当作所有层"的做法。

非单位法向量会被归一化，同时按比例缩放 `offset`（`n·p = c ⟺ (n/|n|)·p = c/|n|`）。
非法输入（`|n| < 1e-9`、`NaN`/`Infinity`、非法 `removedSide`）返回 `null`，
`applyCuts` 跳过该刀并写入 `warnings`，**不崩溃、不改动纸形**。

切割完全落在纸包之外时，`removedPacket` 为空、纸形不变，并给出「这一刀没有碰到折叠后的纸包」。

### 4.1 折剪（bent cut）

一条直线只能把纸剪成**凸**多边形（剩余区域是若干半平面之交）。要让展开图出现**花瓣与尖角**，
剪刀必须在纸包里拐弯。第二种切割原语是「折剪」：

```
{ kind: 'notch', angle, distance, width }
```

它移除一个三角形：顶点在 `angle` 方向、距纸包中心 `distance` 处，张口 `width`，两条边向外
延伸（`NOTCH_REACH = 1.4`，随后被纸包裁掉）。物理上就是从纸包边缘剪入、到顶点转弯、再剪出来，
剪刀不离开纸。

- `distance` 越小 → 缺口越深、花瓣越长；`distance` 越过纸包半径时这一剪落空。
- 在 `radial8` 下，一个折剪会被复制 8 份。注意 **22.5° 与 67.5° 在 D4 下属于同一个轨道**：
  两个方向相差 45° 的折剪会产生完全相同的花瓣；想要第二层，方向必须换到另一个轨道
  （例如 0° 或 45°，它们的轨道只有 4 个元素）。
- 折剪与直线可以叠加：直线负责花心，折剪负责花瓣。

### 4.2 镂空（closed cut-out）

第三种原语：在纸包里**戳一个闭合的小形状**，沿轮廓剪一圈把它取走。剪刀同样不离开纸，
但它不是"一刀"，UI 上也从不这样标注。

```
{ kind: 'hole', shape, angle, radius, size, stretch, rotation }
```

轮廓是一条**超椭圆**，用同一个参数化覆盖三种形状：

```
r(θ) = (|cos θ|^p + |sin θ|^p)^(-1/p)
  p = 1    → 菱形（直边）
  p = 2    → 圆 / 椭圆
  p = 0.62 → 叶形（两端尖、两侧内凹，即 柳叶纹 / 花瓣纹）
```

再按 `rotation` 旋转、平移到 `(radius, angle)`，最后与纸包求交：

```
D_hole = packet ∩ ring(shape, size, stretch, rotation, radius, angle)
```

在 `radial8` 下，一个镂空展开成**一圈 8 个孔**——这正是团花"细密"的来源。
若 `radius = 0`，8 份重合为 1 个中心孔（有测试）。

### 4.3 锯齿（sawtooth row）

锯齿不是新原语，而是**在纸包边缘等距压一排菱形孔**：

```
for i in 0..count-1:
  θ_i   = phase + (i + 0.5) · span / count      # span = 45°（radial8）或 180°
  rim   = 沿 θ_i 从原点射出的第一条纸包边距离
  D_i   = 菱形孔，中心落在 rim 上，径向半长 depth，切向半宽 pitch/2
```

菱形有一半在纸外，留在纸内的一半就是**一个三角齿**。展开后得到 `8 × count` 个齿
（`count = 4` → 32 齿，`count = 5` → 40 齿），这是民间剪纸最典型的外缘处理。
齿深与齿距都从边缘量起，所以楔形收窄处齿形仍然均匀。

**注意**：`sawtooth` 与 `rim` 不要同时使用——`rim` 会把齿所在的那圈纸整体削掉。

### 4.4 曲线（curved stroke）

第四种原语：刀在纸包里**连续转向**。完整设计见 `docs/SCISSOR_CURVES.md`，此处只记契约。

```
{ kind: 'curve', angle, offset, amplitude, bends, removedSide }
```

- `angle / offset / removedSide` 与直线剪**同名同义**（`angle` 是法线方向）；
- `bends ∈ {1,2,3}` 是纸包跨度内的**半波数**，刀口拐点数 = `bends − 1`；
- 在局部标架 `(u, v)`（`v` 为法线）中：

```
v = offset + amplitude · sin( bends · π · t ),   t ∈ [0,1]
移除 { v > 上式 }（removedSide = positive）或其补侧
```

三条硬约束（违反即不是本模型）：

1. **单值**：刀口是 u 的函数，`t → u` 单调。因此不自交、不回头、不闭合。
2. **`amplitude = 0` 必须退化为直线**：与 `{nx: cos(angle), ny: sin(angle), offset}` 的直线剪
   **完全等价**（测试要求纸形差 < 1e-9，不是"接近"）。
3. **采样误差有界**：`N = clamp(ceil(π·bends·√(|A|/(8ε))), 24, 192)`，`ε = 1.2e-3`；
   弦逼近误差 ≤ `|A|·bends²·π²/(8N²)`。目标与作答使用同一个采样器，
   因此近似不会引入系统性评分偏差。

## 5. 展开与结果

```
S = ⋃ᵢ ( Pᵢ \ fᵢ⁻¹( D ∩ fᵢ(Pᵢ) ) )
```

在本实现的预设里 `fᵢ(Pᵢ) = packet`，所以 `D ∩ fᵢ(Pᵢ) = D`，上式化为
`S = P \ ⋃ᵢ fᵢ⁻¹(D)`。

不变量（全部有对应测试）：

| 编号 | 不变量 | 测试 |
|---|---|---|
| I1 | `S ⊆ P` | `remaining paper is always a subset of the original sheet` |
| I2 | `0 ≤ Area(S) ≤ 4` | `paper area never exceeds the original and is never negative` |
| I3 | `Area(S) + Area(removed) = 4` | `paper + removed = the original sheet` |
| I4 | 相同输入 → 相同输出（逐字节） | `same input and same seed give byte-identical geometry` |
| I5 | 变换是等距且自逆 | `each patch transform is an isometry and its own inverse` |

### 5.1 实现方式：一次「纸包内相减」，再逐层撤纸

`applyCuts()` 的权威结果按

```
S = P \ ⨄ᵢ fᵢ⁻¹(D)          （⨄ 表示不相交并；D 是纸包内被剪掉的区域）
```

计算，而不是把各片区的剩余区域并起来。两条路线作为点集相等，但布尔运算的鲁棒性差很多。

**实际故障（2026-10-31 审查修复）**：原实现逐片区做
`region_i = domain_i \ fᵢ⁻¹(D)`、`removed_i = fᵢ⁻¹(D) ∩ domain_i`。
当切口的边缘与纸包 / 片区边界**精确重合**时（曲线贴边、八折的轴线切口、
以及"同一条切口写成相反法向"的情形），`polygon-clipping` 对其中两个片区
返回空的交集 / 未变的差集，于是那两层被当成"没剪"。实测：
同一条曲线写成相反法向（S 形关），纸面 2.2108 vs 2.6581；
团花的 `paper + removed` 只有 3.9314（应为 4）。
这类错误不会抛异常，只会**静默少剪一层**。

修法（现在的管线）：

1. **在纸包坐标里只减一次**：`surviving = packet \ D`。纸包是单个多边形，
   不存在"切口边缘与片区边界重合"的问题。
2. 每个片区只做等距映射：`region_i = fᵢ⁻¹(surviving)`、`removed_i = fᵢ⁻¹(D)`；
   不再对每个片区跑布尔运算。
3. **整纸按层相减**：`S` 从整张纸开始，逐层 `S ← S \ removed_i`。
   八份 `removed_i` 互不相交，逐次相减的每一步都是独立的；实测在
   23°/0.34 处，先并集再相减会丢掉一整层（0.3352 vs 0.3831），逐层相减则精确。
4. `removed` 用**拼接**而不是并集：八份互不相交，拼接在集合意义上就是答案，
   `fill-rule="evenodd"` 的渲染结果也相同。

配套的通用修复：

- `differenceMP` 的逐成员回退分支原来把 `ClipMulti` 套了一层再传给库
  （`[toClip([poly]) as never]`），库直接拒绝，回退实际上"什么都没减"。
  现在传 `toClip([poly])`。
- "B 覆盖 A" 的快速判断原来只看面积；一个面积更大但远离 A 的 B 会被误判为
  覆盖，`A \ B` 直接返回空。现在同时要求 **B 的包围盒包含 A 的包围盒**。

补充不变量（全部有测试）：

| 编号 | 不变量 | 测试 |
|---|---|---|
| I6 | 切口顺序不影响结果（可交换） | `the order of two cuts does not change the sheet` |
| I7 | 镂空数量随折数放大（8 折 → 一圈 8 个） | `8-fold turns one cut-out into a ring of holes` |
| I8 | 各片区的 `region + removed` 等于该片区面积，且总和等于整纸 | `the per-patch pieces add up to the sheet they came from` |
| I9 | 同一刀在每一层剪掉的面积相同 | `every layer of a folded cut loses the same amount of paper` |
| I10 | 同一条切口写成相反法向，纸形不变 | `curveUnderFlippedNormal preserves the sheet…` |

## 6. 黄金样例：正交双折 + 中心菱形

折叠：`orthogonal2`，纸包 `[0,1]²`，`(u,v) = (|x|, |y|)`。
切割：`n = (√2/2, √2/2)`，`offset = c`，`removedSide = 'negative'`。

被剪区域在纸包里是

```
D = { (u,v) : u ≥ 0, v ≥ 0, u + v < d },   d = c√2
```

展开后的孔洞

```
H = { (x,y) ∈ P : |x| + |y| < d }
```

验证数值（`c = 0.4`，`d = 0.565685…`）：

| 量 | 理论值 | 实测（测试断言） |
|---|---|---|
| 孔洞顶点 | `(±d,0), (0,±d)` | 点包含检验通过 |
| 孔洞面积 | `2d² = 0.64` | `toBeCloseTo(0.64, 9)` |
| 原纸面积 | `4` | — |
| 剩余面积 | `4 − 2d² = 3.36` | `toBeCloseTo(3.36, 9)` |
| 关于两轴的反射 | 不变 | 361 个采样点逐一验证 |
| 每层各自失去 | `2d²/4 = 0.16` | 四个片区逐一断言 |

**改 `d` 就是改几何**：`d ∈ {0.2,0.3,0.4,0.5}` 时孔洞面积严格按 `2d²` 变化，
不是切换预置图片。

## 7. 评分

对实得纸形 `A` 与目标 `T`：

```
IoU = Area(A ∩ T) / Area(A ∪ T)
E   = Area(A △ T) / Area(P) = Area(A △ T) / 4
```

判定按**阶段**取阈值（`STAGE_THRESHOLDS`），四档：

| 判定 | 条件 | 是否通关 |
|---|---|---|
| 完全匹配 `exact` | `IoU ≥ 0.995` | 是（额外徽章） |
| 达标 `pass` | `IoU ≥ passIou` | 是 |
| 接近 `near` | `IoU ≥ passIou − 0.06` | 否，但给方向提示 |
| 未达标 `miss` | 其余 | 否 |

| 阶段 | `passIou` |
|---|---|
| 1 看懂折叠 | 0.92 |
| 2 对齐参数 | 0.94 |
| 3 叠加切口 | 0.96 |

`E`（对称差比例）不再参与判定，只作为展示指标：它和 IoU 高度相关，
双条件会额外制造"IoU 明明够了却被判失败"的情况。

**容差下限有测试保证**：任意一个参数偏离标准解恰好一个 UI 步长（角度 0.5°、距离 0.01），
IoU 最低仍有 98.0%（八角星），因此三个阶段的门槛都落在"一格必过"之内。
见 `geometry.test.ts > one slider step never fails any level`。

边界情况：`A ∪ T` 面积为 0 时，两者皆空记 `IoU = 1`，否则记 `0`（不产生 `NaN`）。
差异可视化：`extra = A \ T`（多剪，青色），`missing = T \ A`（少剪，金色）。

## 8. 关卡目标必须由正向构造生成

`src/puzzle/levels.ts` 的 `buildLevel()` 用**标准解**跑一遍 `applyCuts`，
把得到的 `paper` 作为 `target`。若结果退化（面积 ≤ 1e-6）则模块加载时抛错。
因此"这一关有解"是数据本身的性质，而非文档里的声明。

| # | 关卡 | 折叠 | 切口 | 图案类型 | 复杂度 |
|---|---|---|---|---|---|
| 1 | 角落初探 | none | 直线 45°/0.99/正侧 | 缺角 | 1 层 · 1 段 |
| 2 | 镜像之门 | vertical | 直线 45°/1.16/正侧 | 双缺角（镜像） | 2 层 · 1 段 |
| 3 | 菱形奇迹 | orthogonal2 | 直线 45°/0.40/负侧 | 中心菱形孔 | 4 层 · 1 段 |
| 4 | 八角星 | radial8 | 折剪 22.5°/0.45/张 0.45 | 八道放射尖角 | 8 层 · 2 段 |
| 5 | 团花 | radial8 | 直线 22.5°/0.26/负侧 + 折剪 22.5°/0.55/0.40 | 八角花心 + 八瓣 | 8 层 · 3 段 |
| 6 | 万象团花 | radial8 | 直线 22.5°/0.30/负侧 + 折剪 22.5°/0.50/0.36 + 折剪 0°/0.82/0.34 | 花心 + 八主瓣 + 四轴次瓣 | 8 层 · 5 段 |

**为什么 4–6 关不是"一刀"**：数学上，一条直线与任意对称群作用下的并集仍然是"若干半平面之交"，
只能是凸多边形。第 1–3 关严格保持「一刀一条直线」；第 4–6 关引入**折剪**（剪刀拐一个弯），
在 UI 上分别标注为「1 个折剪」「1 条直线 + 1 个折剪」「1 条直线 + 2 个折剪」，
不会被说成"一刀"。

标准解只使用 UI 可精确取到的值（整数角度、两位小数 offset），玩家可以完全复现。

---

## 9. 渲染与导出

- 渲染：`multiPolygonToPath(mp, {mat})` 把每个环转成 `M…L…Z` 子路径，
  统一用 `fill-rule="evenodd"`，因此孔洞是真正透明的区域。
- 折叠相机：`foldedness > 0.72` 时把 `viewBox` 平滑推近到纸包（`packetView`），
  保证折叠状态下可点面积不会缩到 1/4。**注意 `viewBox` 的 y 是 SVG 坐标**，
  其中心必须取数学中心的相反数。
- 导出 SVG：`exportPath` 把图案等比缩放到 `1000×1000`（边距 56），
  路径来自几何结果，不是位图；PNG 由同一路径字符串经 `Path2D` 在 2000×2000 画布填充。

## 10. 模型边界（不得越界宣称）

1. **只支持五种固定折法**（不折 / 竖折 / 横折 / 正交双折 / 八折）。斜折、任意折线、曲线折痕均未实现，也不能由当前代码推导。
2. 一刀挑战中**严格只有一条直线**。工坊的多切口是自由创作，标注为数字图案。
3. Fold-and-Cut 定理（Demaine–Demaine–Lubiw）断言的是"**存在**一种平折"，
   **不等于**两次简单对折可剪出任意图案，也不等于任意折法都行。原文与译文见
   `src/pages/ExplorePage.tsx` 第 5 张卡片。
4. 未提供实体可制造性核验；`manufacturability` 只取 `unchecked` / `digital-only`，
   代码中没有任何路径会写入 `verified`。
5. 折叠动画端点精确，但**不是纸张物理仿真**（不做弯曲、厚度、碰撞）。
6. **曲线是正弦弧，不是真圆弧**；且只覆盖"开口的单值路径"，自交与闭合不在模型内
   （闭合用 `hole`，拐弯折线用 `notch`）。详见 `docs/SCISSOR_CURVES.md` §1.2 与 §6。
