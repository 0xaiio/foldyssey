# 几何规格（GEOMETRY_SPEC）

本文是实现与验收的**唯一几何契约**。修改 `src/geometry/` 时必须同步本文与
`src/tests/geometry.test.ts`。

---

## 1. 坐标与单位

| 名称 | 定义 |
|---|---|
| 纸张坐标（paper） | 初始纸是 `P = [-1,1] × [-1,1]`，即边长 `a = 1`，面积 `4` |
| 纸包坐标（packet） | 折叠后所有层叠在一起的区域，由预设给出（见 §3） |
| SVG 坐标 | `viewBox` 由相机给出，绘制组带 `transform="scale(1,-1)"`，因此**数学 y 向上、SVG y 向下** |
| 角度 | 法向量极角，单位度，取值 `[0, 180)`（`n` 与 `-n` 加翻面等价） |
| 长度 | 与纸张边长同单位（`a = 1`），无物理单位 |

布尔运算的容差：面积小于 `1e-9` 的碎片被丢弃；坐标保留 5 位小数输出到 SVG。
`polygon-clipping` 的输入输出没有显式容差，退化多边形由 `cleanRing` 去重处理。

## 2. 纸张模型

初始纸被划分为若干**片区** `Pᵢ`（互不重叠、并集为 `P`）。每个片区带一个仿射等距变换

```
fᵢ(x) = Rᵢ x + tᵢ ,   Rᵢᵀ Rᵢ = I
```

把 `Pᵢ` 映到纸包，并记录其逆 `fᵢ⁻¹`。实现的四个预设中所有 `Rᵢ` 都是对角符号矩阵
（`diag(±1, ±1)`），`tᵢ = 0`，因此 `fᵢ = fᵢ⁻¹`。

片区还记录：`layer`（绘制/层序）、`flips`（在哪条轴上被镜像，用于折叠动画）。

> **关键区别**：二维几何决定最终形状；动画只描述过程。`PaperStage` 不构造第二套结果状态。

---

## 3. 折叠预设

| id | 纸包 packet | 片区数 | 变换 | 对称 |
|---|---|---|---|---|
| `none` | `[-1,1]²` | 1 | 恒等 | 无 |
| `vertical` | `[0,1] × [-1,1]` | 2 | 右半恒等；左半 `(x,y)↦(−x,y)` | 关于 `x=0` 镜像 |
| `horizontal` | `[-1,1] × [0,1]` | 2 | 上半恒等；下半 `(x,y)↦(x,−y)` | 关于 `y=0` 镜像 |
| `orthogonal2` | `[0,1]²` | 4 | 四个象限分别用 `(±x, ±y)` 映到第一象限 | 四重镜像 |

`orthogonal2` 的四片区：

| 片区 | 区域 | forward / inverse |
|---|---|---|
| q1 | `[0,1]×[0,1]` | 恒等 |
| q2 | `[-1,0]×[0,1]` | `(−x, y)` |
| q3 | `[-1,-1]×[0,0]` | `(−x, −y)` |
| q4 | `[0,-1]×[1,0]` | `(x, −y)` |

折叠动画把每个被镜像的轴表示为缩放 `+1 → −1`（经过 0），端点精确、中间帧是
**二维步骤化示意**，见 `patchRenderMatrix()`。`orthogonal2` 的两步在时间上重叠
（`t ∈ [0,0.55]` 竖折，`t ∈ [0.45,1]` 横折）。

## 4. 直线切割语义

一条切割由 `{n, offset, removedSide}` 给出，`|n| = 1`：

```
removedSide = 'negative'  →  移除  { p : n·p < offset }
removedSide = 'positive'  →  移除  { p : n·p > offset }
```

**被移除的是半平面（有面积），不是零宽度的线。** 实现步骤：

1. 用 Sutherland–Hodgman 把足够大的矩形裁到目标半平面，得到 `H`；
2. `D = packet ∩ H`（纸包坐标）；
3. 对每个片区：`holeᵢ = fᵢ⁻¹(D)`，`regionᵢ ← regionᵢ \ holeᵢ`；
4. 展开结果 `S = ⋃ᵢ regionᵢ`。

因此**每一层都被独立剪一次**，不存在"只剪一遍当作所有层"的做法。

非单位法向量会被归一化，同时按比例缩放 `offset`（`n·p = c ⟺ (n/|n|)·p = c/|n|`）。
非法输入（`|n| < 1e-9`、`NaN`/`Infinity`、非法 `removedSide`）返回 `null`，
`applyCuts` 跳过该刀并写入 `warnings`，**不崩溃、不改动纸形**。

切割完全落在纸包之外时，`removedPacket` 为空、纸形不变，并给出「这一刀没有碰到折叠后的纸包」。

## 5. 展开与结果

```
S = ⋃ᵢ ( Pᵢ \ fᵢ⁻¹( D ∩ fᵢ(Pᵢ) ) )
```

在本实现的预设里 `fᵢ(Pᵢ) = packet`，所以 `D ∩ fᵢ(Pᵢ) = D`，上式化为
`S = P \ ⋃ᵢ fᵢ⁻¹(D)`。

不变量（全部有对应测试）：

| 编号 | 不变量 | 测试 |
|---|---|---|
| I1 | `S ⊆ P` | `remaining paper is always a subset of the original sheet` |
| I2 | `0 ≤ Area(S) ≤ 4` | `paper area never exceeds the original and is never negative` |
| I3 | `Area(S) + Area(removed) = 4` | `paper + removed = the original sheet` |
| I4 | 相同输入 → 相同输出（逐字节） | `same input and same seed give byte-identical geometry` |
| I5 | 变换是等距且自逆 | `each patch transform is an isometry and its own inverse` |

## 6. 黄金样例：正交双折 + 中心菱形

折叠：`orthogonal2`，纸包 `[0,1]²`，`(u,v) = (|x|, |y|)`。
切割：`n = (√2/2, √2/2)`，`offset = c`，`removedSide = 'negative'`。

被剪区域在纸包里是

```
D = { (u,v) : u ≥ 0, v ≥ 0, u + v < d },   d = c√2
```

展开后的孔洞

```
H = { (x,y) ∈ P : |x| + |y| < d }
```

验证数值（`c = 0.4`，`d = 0.565685…`）：

| 量 | 理论值 | 实测（测试断言） |
|---|---|---|
| 孔洞顶点 | `(±d,0), (0,±d)` | 点包含检验通过 |
| 孔洞面积 | `2d² = 0.64` | `toBeCloseTo(0.64, 9)` |
| 原纸面积 | `4` | — |
| 剩余面积 | `4 − 2d² = 3.36` | `toBeCloseTo(3.36, 9)` |
| 关于两轴的反射 | 不变 | 361 个采样点逐一验证 |
| 每层各自失去 | `2d²/4 = 0.16` | 四个片区逐一断言 |

**改 `d` 就是改几何**：`d ∈ {0.2,0.3,0.4,0.5}` 时孔洞面积严格按 `2d²` 变化，
不是切换预置图片。

## 7. 评分

对实得纸形 `A` 与目标 `T`：

```
IoU = Area(A ∩ T) / Area(A ∪ T)
E   = Area(A △ T) / Area(P) = Area(A △ T) / 4
```

判定阈值（`DEFAULT_THRESHOLDS`）：

| 判定 | 条件 |
|---|---|
| 完全匹配 | `IoU ≥ 0.99` 且 `E ≤ 0.02` |
| 接近 | `IoU ≥ 0.90` |
| 未匹配 | 其余 |

边界情况：`A ∪ T` 面积为 0 时，两者皆空记 `IoU = 1`，否则记 `0`（不产生 `NaN`）。
差异可视化：`extra = A \ T`（多剪，青色），`missing = T \ A`（少剪，金色）。

## 8. 关卡目标必须由正向构造生成

`src/puzzle/levels.ts` 的 `buildLevel()` 用**标准解**跑一遍 `applyCuts`，
把得到的 `paper` 作为 `target`。若结果退化（面积 ≤ 1e-6）则模块加载时抛错。
因此"这一关有解"是数据本身的性质，而非文档里的声明。

| # | 关卡 | 折叠 | 法线角 | offset | 剪去 | 形状 |
|---|---|---|---|---|---|---|
| 1 | 角落初探 | none | 45° | 0.99 | 正侧 | 削掉一个角 |
| 2 | 镜像之门 | vertical | 45° | 1.16 | 正侧 | 左右两个缺角 |
| 3 | 菱形奇迹 | orthogonal2 | 45° | 0.40 | 负侧 | 中心菱形孔 |
| 4 | 大小之谜 | orthogonal2 | 45° | 1.13 | 正侧 | 四角削平 → 八边形 |
| 5 | 角度之谜 | orthogonal2 | 30° | 0.42 | 负侧 | 四叶风车孔 |
| 6 | 一刀终章 | vertical | 61° | 0.88 | 正侧 | 山形剪影 |

标准解只使用 UI 可精确取到的值（整数角度、两位小数 offset），玩家可以完全复现。

## 9. 渲染与导出

- 渲染：`multiPolygonToPath(mp, {mat})` 把每个环转成 `M…L…Z` 子路径，
  统一用 `fill-rule="evenodd"`，因此孔洞是真正透明的区域。
- 折叠相机：`foldedness > 0.72` 时把 `viewBox` 平滑推近到纸包（`packetView`），
  保证折叠状态下可点面积不会缩到 1/4。**注意 `viewBox` 的 y 是 SVG 坐标**，
  其中心必须取数学中心的相反数。
- 导出 SVG：`exportPath` 把图案等比缩放到 `1000×1000`（边距 56），
  路径来自几何结果，不是位图；PNG 由同一路径字符串经 `Path2D` 在 2000×2000 画布填充。

## 10. 模型边界（不得越界宣称）

1. **只支持四种固定折叠**。斜折、任意折线、曲线折痕均未实现，也不能由当前代码推导。
2. 一刀挑战中**严格只有一条直线**。工坊的多切口是自由创作，标注为数字图案。
3. Fold-and-Cut 定理说的是"存在某个一般平折"，**不等于**两次简单对折可剪出任意图案。
4. 未提供实体可制造性核验；`manufacturability` 只取 `unchecked` / `digital-only`，
   代码中没有任何路径会写入 `verified`。
5. 折叠动画端点精确，但**不是纸张物理仿真**（不做弯曲、厚度、碰撞）。
