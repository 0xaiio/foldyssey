# ADR-0001：二维精确几何优先于纸张物理引擎

- **状态**：已采纳（v0.1.0）
- **日期**：2026-10-30

## 背景

一刀剪切的**结果**是一个平面区域，与纸张的刚度、厚度、重力、碰撞无关。
但"折叠"这个过程本身在现实中是柔软的三维形变。首版需要在 48 小时内交付
可验证的数学结果。

## 决策

只实现**二维精确几何**：保距变换 + 半平面裁剪 + 多边形布尔运算。
不引入 Matter.js / Rapier 等物理引擎。折叠动画用二维插值表达（端点精确）。

## 后果

- 正面：结果可证明、可测试、确定性、性能好；黄金样例的孔洞面积精确等于 `2d²`。
- 负面：折叠动画不是三维仿真，观感有限；不支持自遮挡、曲面折痕。
- 缓解：About 页明确写明"二维步骤化示意，不是物理仿真"。

## 替代方案

| 方案 | 否决理由 |
|---|---|
| 物理引擎模拟软纸 | 不改变最终平面结果，只增加不确定性与调试成本 |
| Three.js 三维折叠 | 首版视觉收益不足以抵消工期风险；且必须与几何引擎严格分离 |
