# ADR-0004：开发期 AI 与运行时 AI 严格分离

- **状态**：已采纳（v0.1.0）
- **日期**：2026-10-30

## 背景

"用 WorkBuddy 开发了这个应用"与"这个应用在运行时调用大模型"是两件事。
把两者混为一谈是最常见的 AI 套壳叙事。

## 决策

- v0.1.0 **不接入**运行时模型；页面零网络请求。
- 在 `README`、About 页、`submission/ai_usage_disclosure.md` 中分别写明：
  - 开发期：使用 WorkBuddy 辅助（代码/文档/测试）。
  - 运行期：无模型调用。
- 为将来的接入保留设计文档 `docs/AI_INTEGRATION.md`（Schema、限流、降级、密钥边界）。

## 后果

- 正面：核心体验不受第三方服务影响；披露诚实，经得起追问。
- 负面：若赛事强制要求应用内 AI，会缺一项。
- 触发条件：只有在核实官方规则"强制"后，才把 AI 提升为 P0 并重新评估工期。
