# ADR-0002：SVG + 轻量插值动画，而不是首版上 Three.js

- **状态**：已采纳（v0.1.0）
- **日期**：2026-10-30

## 背景

纸张、折痕、切线、镂空都是二维图形；导出也必须是矢量。

## 决策

- 渲染层全部用 SVG：`<path>` + `fill-rule="evenodd"`，孔洞是真实透明区域。
- 折叠动画把"沿折痕翻折"表示为沿该轴的缩放 `+1 → −1`（经过 0），
  相位由 `foldedness ∈ [0,1]` 驱动，用 rAF 补间，不依赖动画库。
- 相机（`viewBox`）随折叠推近纸包，保证折叠时仍有可点面积。

## 后果

- 正面：零额外渲染依赖、路径即导出、移动端流畅、可访问性好。
- 负面：没有真正的三维遮挡与光影；极端角度下折痕视觉不完美。
- 记录：中间帧是**示意**，但端点与几何引擎完全一致，不构造第二套结果。

## 替代方案

- Canvas 渲染：导出需重画一遍，且缩放模糊。
- Three.js：见 ADR-0001。
