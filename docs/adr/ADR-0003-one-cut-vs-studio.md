# ADR-0003：一刀挑战与自由剪纸的几何语义隔离

- **状态**：已采纳（v0.1.0）
- **日期**：2026-10-30

## 背景

产品有两个模式：关卡要求"只剪一刀"，工坊允许自由创作。
如果把两者混在一个宽松的模型里，"一刀"就会变成营销话术。

## 决策

| | 一刀挑战 | 剪纸工坊 |
|---|---|---|
| 切口数量 | **严格 1 条** | 最多 3 条（自由创作） |
| 评分 | IoU + 对称差，有目标 | 无评分 |
| 可制造性标注 | 未核验 | 单切口 `unchecked`，多切口 `digital-only` |
| 数据 | `canonicalSolution: StraightCut` | `cuts: StraightCut[]` |

类型上两者共用 `StraightCut`，但关卡入口 `applyCuts(preset, [cut])` 只接受一个元素；
工坊入口接受数组。UI 文案明确区分"一刀"与"多刀创作"。

## 后果

- 正面：不会出现"多个切口合称一刀"的伪完成。
- 负面：工坊的表达力受限（≤3 条直线）。
- 约束：代码中**没有任何路径**会写入 `manufacturability: 'verified'`，
  因为尚未做实体可制造性核验。
