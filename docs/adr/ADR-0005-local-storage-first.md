# ADR-0005：本地存储优先与隐私边界

- **状态**：已采纳（v0.1.0）
- **日期**：2026-10-30

## 背景

作品集需要持久化。可选：云数据库、账号体系、localStorage。

## 决策

- 全部数据留在浏览器 localStorage（`foldyssey.artworks.v1` / `foldyssey.progress.v1`）。
- 只存**结构化参数**，不存图片；打开作品时用几何引擎重新计算。
- 版本号 `schemaVersion: 1`；读到未知版本直接忽略（不崩溃、不猜测迁移）。

## 后果

- 正面：零账号、零后端、零隐私面、断网可用、首屏无等待。
- 负面：换设备/清缓存即丢失。
- 缓解：显眼的「导出 SVG / PNG」，并在作品页提示"清缓存会丢失"。

## 何时重新评估

- 需要跨设备同步、分享链接、多人协作时。
- 届时引入云服务必须同时引入账号与数据删除能力，不能只加"上传"。
