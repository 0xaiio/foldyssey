# 作品介绍（Entry Description）

> 与 v0.7.4 的代码一致。数字都可以在仓库里复核：16 关（`src/puzzle/levels.ts`）、
> 5 种折法（`src/geometry/fold.ts`）、4 种刀具（`src/geometry/cut.ts`）、
> 214 个测试与 96.7% 行覆盖率（`npx vitest run`、`npx vitest run --coverage`）。

## 一句话亮点

折起一张纸，只剪一刀，再亲手展开——图案不是画出来的，是算出来的。

## 100 字版

Foldyssey（一刀万象）是一座可以玩的数字折剪纸实验室。你选一种折法、拖动一条切线、按下「剪一刀」，
层层纸同时被剪开，逐层展开后得到一个对称的镂空图案。所有形状都由计算几何实时生成，
可以挑战十六个图案，也可以在工坊里自由创作并导出 SVG。

## 300 字版

Foldyssey 把「折纸」和「剪纸」拆成两个可以看的数学动作。

折叠时，纸张被划分成几块，每一块用一个保距变换叠到同一位置；剪切时，你剪掉的不是一个「形状」，
而是纸包上的一个区域——这一刀会同时作用在每一层纸上。展开时，程序把每一层各自被剪掉的部分
逆向映射回原纸，再相减，就得到你看到的图案。

因此改变切线的角度、位置或弯曲，结果会真的变；评分比较的是几何集合的交并比，而不是「看起来像不像」。

图案库里有十六个图案，分五个阶段递进：从「削掉一个角」到八折团花，到「八方连珠 / 藻井 / 菱窗 / 六出 / 重瓣」
五个典藏纹样，最后是「波边 / 旋风 / 葫芦 / 花窗」四个让刀转弯的曲线关；
每个图案都附折叠结构、切割逻辑与展开效果说明，并给出可复现的标准解。
工坊里可以叠多条切口、在直线 / 折剪 / 镂空 / 曲线之间随时换刀、换配色、撤销重做，并把作品导出为矢量图。
想不出主题时，可以对着「AI 灵感」说一句话——模型把它翻译成折叠阶数、结构元素与配色，
再由同一个几何引擎画出来，结果可以直接带回工坊继续改。

## 500 字版

（在 300 字版基础上补充以下两段）

**为什么它不只是动画。** 纸张 `P = [−1, 1]²` 被折叠划分成片区 `Pᵢ`，每片带一个保距变换 `fᵢ`。
一刀剪掉的区域 `D` 在纸包里，展开结果等于 `S = P − ⋃ᵢ fᵢ⁻¹(D)`。这个式子写在「关于」页里，
也写成了测试：每一关的「纸 + 剪掉的部分」必须等于整张纸（误差 < 1e-6）、每一层失去的面积必须相等、
两刀交换顺序后纸形不变、同一条切口写成相反法向时纸形不变。曲线关另有独立的一条：
`amplitude = 0` 时曲线剪与同参数直线剪**严格等价**（纸形差 < 1e-9），折线逼近的误差有闭式上界
`|A|·bends²·π²/(8N²) ≤ 1.2×10⁻³`，且目标与作答共用同一个采样器。

**边界也写清楚。** 折法只有五种固定预设（不折 / 竖折 / 横折 / 正交双折 / 八折团花），
不支持任意斜折与任意目标图案的自动求解；切割有直线、折剪、镂空、曲线四种原语（锯齿边由菱形镂空排成），
曲线是正弦弧的折线逼近、不支持自交、回头或闭口的开口剪，折叠动画是端点精确的二维示意，
不是纸张物理仿真。AI 灵感页接入云端模型，但模型只挑参数（结构元素、对称阶数 1/2/4/8、配色），
不生成图片，也不能越过 Schema 的边界——图案永远由本机的几何引擎算出来。

## 主要功能

| 模块 | 内容 |
|---|---|
| 一刀挑战 | **16 关 / 5 阶段**、折叠与展开动画、目标对照、IoU 四档评分、差异覆盖、一键诊断、「剪刀能力」四级分级 |
| 剪纸工坊 | 折叠纸包与展开预览双视图、最多 3 条切口、**四种刀型互转**、5 套配色、撤销/重做、SVG/PNG 导出 |
| AI 灵感 | 一句话描述主题 → 受约束的结构参数 → 真实图案，可一键交接到工坊继续编辑；6 个可编辑模板 |
| 我的作品 | 本地作品集，可再次编辑、导出、删除 |
| 纸艺中的数学 | 5 张交互卡片：轴对称、层叠、一刀、逆映射、Fold-and-Cut 定理（含英文原文与出处） |
| 关于 | 数学摘要（LaTeX→SVG 编译的公式）、能力边界、研究灵感与免责、隐私说明 |

## 技术栈

React 18 + TypeScript + Vite + Tailwind v4；`polygon-clipping`（MIT）做布尔运算；
MathJax 只在**构建期**把 LaTeX 编译成自包含 SVG；模型调用走 WorkBuddy 云通道，客户端不含密钥。
