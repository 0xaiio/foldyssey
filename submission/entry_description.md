# 作品介绍（Entry Description）

## 一句话亮点

折起一张纸，只剪一刀，再亲手展开——图案不是画出来的，是算出来的。

## 100 字版

Foldyssey（一刀万象）是一座可以玩的数字折剪纸实验室。你选一种折叠、拖动一条切线、按下"剪一刀"，
四层纸同时被剪开，逐层展开后得到一个对称的镂空图案。所有形状都由计算几何实时生成，
可以挑战十一个图案，也可以在工坊里自由创作并导出 SVG。

## 300 字版

Foldyssey 把"折纸"和"剪纸"拆成两个可以看的数学动作。

折叠时，纸张被划分成几块，每一块用一个保距变换叠到同一位置；剪切时，你剪掉的不是一个"形状"，
而是纸包上的半个平面——这一刀会同时作用在每一层纸上。展开时，程序把每一层各自被剪掉的部分
逆向映射回原纸，取并集，就得到你看到的图案。

因此改变切线的角度或位置，结果会真的变；评分比较的是几何集合的 IoU，而不是"看起来像不像"。

图案库里有十一个图案，分四段递进：从"削掉一个角"到八折团花，再到"八方连珠 / 藻井 / 菱窗 / 六出 / 重瓣"五个典藏纹样；
每个图案都附折叠结构、切割逻辑与展开效果说明，并给出可复现的标准解。
工坊里可以叠多条切口、换配色、撤销重做，并把作品导出为真正的矢量图。
想不出主题时，可以对着「AI 灵感」说一句话——模型把它翻译成折叠阶数、切割原型、尺寸与配色，
再由同一个几何引擎画出来，结果可以直接拎回工坊继续改。

## 500 字版

（在 300 字版基础上补充以下两段）

**为什么它不只是动画。** 纸张 `P=[-1,1]²` 被折叠划分成片区 `Pᵢ`，每片带一个等距变换 `fᵢ`。
一刀是半平面 `D`，展开结果严格等于 `S = ⋃ᵢ (Pᵢ \ fᵢ⁻¹(D))`。这个式子写在关于页里，
也写成了 29 个单元测试：黄金样例的孔洞面积必须精确等于 `2d²`，必须关于两条坐标轴都对称，
改变 `d` 时面积必须按真实关系变化，相同输入必须得到逐字节相同的路径。

**边界也写清楚。** 折法只有五种固定预设（不折 / 竖折 / 横折 / 正交双折 / 八折团花），
不支持任意斜折与任意目标图案的自动求解；切割有直线、折剪、镂空、锯齿与曲线五种刀具，
但曲线是正弦弧的折线逼近、不支持自交或闭口路径，折叠动画是端点精确的二维示意，
不是纸张物理仿真。AI 灵感页接入了云端模型，但模型只挑参数（五种直线切割原型、
对称阶数 1/2/4、配色），不能生成图片，也不能越过 Schema 的边界——
图案永远由本机的几何引擎算出来。

## 主要功能

| 模块 | 内容 |
|---|---|
| 一刀挑战 | 6 关、折叠/剪切/展开动画、目标对照、IoU 评分、差异覆盖、三级提示、进度记录 |
| 剪纸工坊 | 折叠纸包与展开预览双视图、最多 3 条切口、5 套配色、撤销/重做、SVG/PNG 导出 |

| 纸艺中的数学 | 5 张交互卡片：轴对称、层叠、一刀、逆映射、Fold-and-Cut 定理 |
| 关于 | 数学摘要、能力边界、研究灵感与免责、隐私说明 |
