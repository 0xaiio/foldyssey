## 二、亮点（评委扫读版，每条一句话）

1. **不是播动画，是算图形。** 折叠是逐面保距映射，一刀是一次集合差，展开后的纸恒等于
   `S = P − ⋃ fᵢ⁻¹(D)`；每一关的目标都由标准解**正向生成**，"有解"是数据的性质。
2. **判定可量化。** 评分用几何交并比，四档（完全匹配 / 达标 / 接近 / 未达），
   分阶段容差 92 / 94 / 96 / 96 / 96%，并且实测过「一格滑块不会把通过变成失败」（最差 96.55%，仍高出达标线 ≥1 个点）。
3. **刀具是真的多样。** 直线（半平面）/ 折剪（V 形）/ 镂空（闭合孔）/ 曲线（弧线、S 形、波浪）。
   曲线是高度场上的单值刀口，`amplitude = 0` 与直线剪**严格等价**，逼近误差有闭式上界 ≤ 1.2×10⁻³。
4. **分级由几何算出来。** 「一刀 / 两刀 / 拐弯 / 曲线」四级由 `skillOf(标准解)` 计算，
   并用「曲边占比」实测（曲线关 ≥ 65%，纯直线关 0%），界面不能自称做不到的事。
5. **工程可信。** 214 个自动化测试、核心 17 个模块行覆盖率 96.7%；
   一次全面审查修掉了 3 个「静默少剪一层」的布尔运算缺陷，并把不变量写成测试。
6. **AI 只做它该做的。** 模型输出结构参数（元素、对称阶数、配色），越界就夹紧、非法就拒绝；
   图案永远由本机几何引擎画出来，客户端不含密钥。
