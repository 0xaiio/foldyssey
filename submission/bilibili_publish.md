## 4. 简介（可直接粘贴）

```
折起一张纸，只剪一刀，再亲手展开——图案不是画上去的，是算出来的。

Foldyssey（一刀万象）是一座可以玩的数字折剪纸实验室：
选一种折法（不折 / 竖折 / 横折 / 正交双折 / 八折），拖动切线，按下「剪一刀」，
层层纸同时被剪开，再逐层展开，得到一个对称的镂空图案。
每一关的图案都由标准解正向生成，评分比的是几何集合的交并比，不是「看起来像不像」。

▍这一版能做什么
· 16 个原创图案、5 个阶段、按「剪刀能力」分四级：一刀 / 两刀 / 拐弯 / 曲线
· 4 种切割原语：直线、折剪（V 形）、镂空（闭合孔）、曲线（弧线 / S 形 / 波浪）
· 曲线是高度场上的单值刀口，amplitude=0 时与直线剪严格等价，逼近误差有闭式上界
· 剪纸工坊：四种刀型互转、实时双视图、导出 SVG
· 「AI 灵感」：一句话 → 受约束的结构参数 → 由本机几何引擎画出图案

▍章节
00:00 序：折 → 剪 → 展
00:09 折剪定理：1999 年，Demaine 父子与 Anna Lubiw 证明了什么
00:39 作品：三步，看见几何
00:57 原理：一条公式，一次集合差
01:26 手感：容差不是拍脑袋定的，一格滑块还剩多少 IoU
02:08 图案：16 个图案，最后四关让刀转弯
02:41 工坊与模型：四种刀型，和「不合规就拒绝」
03:10 可信度：214 个测试、96.7% 行覆盖率，以及审查修掉的 3 个静默缺陷
03:36 尾
```
