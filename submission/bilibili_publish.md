## 1. 标题

### 1.1 主标题（定稿）

**一刀万象：一个能玩的数字剪纸实验室**（17 字，远低于 80 字上限）

为什么是它：

- **信息优先**：前半是名字，后半一句话说清「是什么 + 能干什么」；不靠感叹号也有信息量。
- **承诺兑现**：片子里确实能玩——16 关可以一关关过，工坊可以拖、可以改参数、可以导出，不是看一段动画。
- **检索友好**：「剪纸 / 折纸 / 实验室」三个词都在，站内搜索能命中。
- **与封面不重复**：封面说的是「折起来，只剪一刀」，标题说的是「这是什么」，两块信息互补。

### 1.2 备选（B 站风格，按「能玩 / 可交互」强度排序）

| # | 标题 | 字数 | 打法 | 什么时候用 |

| A | 拖一条线，纸就自己开了｜我做了个能玩的剪纸实验室 | 24 | 把交互写成动作，前半句就是演示 | 想突出「实时预览」这一下 |
| B | 一刀剪出八瓣团花？十六关剪纸挑战，你能过几关 | 22 | 挑战 + 第二人称，评论区容易接话 | 想冲互动与弹幕 |

使用建议：

- 只换标题不换封面时，选 **A 或 B**——它们和封面上的「剪一刀」字面对得上。
- 标题里**不要出现「AI」**：片子里 AI 灵感只占 17 秒，标题许愿过大，评论区会跑偏。
- B 站信息流一般只露前两行，把「能玩 / 剪纸 / 实验室」放前半句，限定词别堆在末尾。
- 备选都保留了「能玩」这个动词短语，这是本片与「剪纸科普」「折纸教程」这两类存量内容的区别。

## 2. 合集：0xaiio

### 2.1 定位

`0xaiio` 是**作品集**，不是栏目：只收「我自己做的、观众能直接上手的东西」。
一条片子对应一个作品，观众从合集点进来，任意一集都能当场玩，不需要前情。

这决定了三件事：不做「第 N 期」口播、不在片尾做下集预告、合集简介不写更新承诺日期。

### 2.2 合集资料

| 项 | 内容 |
|---|---|
| 名称 | `0xaiio`（沿用现有合集名） |
| 书名号 / 副标识 | 无。名字本身就是标识，加副标题会稀释 |
| 封面 | 16:9，1146×717 或 1920×1080，多作品拼贴 + 左下角合集名 |
| 简介 | 见下，可直接粘贴 |

若账号下还没有这个合集，建议名 `0xaiio · 能玩的作品`——搜索结果里能自带信息；已经建好的话**不要改名**，改名会打断已有分享链接在观众那边的认知。

### 2.3 归类规则

| 内容 | 入集 | 位置 | 时长 |
|---|---|---|---|
| 作品总览（正片） | 是 | 前段，一个作品一条 | 3–5 min |
| 单功能深挖 / 制作过程（番外） | 是 | 紧挨对应正片之后 | 1–3 min |
| 版本更新 / 新关卡 | 是 | 末尾，按时间倒序 | ≤ 90 s |
| 纯讲解、转载、合作、直播回放 | 否 | — | — |

现在只有这一条正片，就先只放它。**不要开空小节**——合集页会露出空白 tab，比没有小节更难看；攒到 6 条以上再分「作品 / 番外 / 更新」三节（上限 10 节）。

### 2.4 展示与排序

| 项 | 设置 | 理由 |
|---|---|---|
| 排序方式 | 手动排序（输入序号 / 拖拽） | 默认按投稿时间，以后番外多了会把正片挤下去 |
| 本片序号 | **1** | 新观众第一眼看到的是总览，不是某次更新 |
| 连播 | **开**（编辑页若有「连播」开关，确认打开） | 看完自动进下一集，合集才有「连着看」的意义 |
| 空间防刷屏 | 先不开，≥3 集再开 | 只有一集时开了没效果，还会挡住后续更新 |
| 动态防刷屏 | **不勾** | 首播需要更新提醒；以后补小更新再勾，避免打扰关注者 |

发布后要核对的出镜位置：视频页播放器下方的「合集」卡片、简介上方的合集入口、个人空间「合集」区。

### 2.5 操作路径（两种顺序，按合集是否已存在选）

**路径 A：合集已存在（推荐，过审即入集）**

1. 上传页填完基础信息 → 展开「更多设置」→「加入合集」→ 选 `0xaiio`。
2. 提交前再确认一次：**「动态防刷屏」投递后不可修改**，其余可改。
3. 过审后进「合集管理」，确认本片排在 1。

**路径 B：合集还不存在（账号没有已过审单 P 稿件时）**

1. 先按普通稿件发布本片，等过审。
2. 创作中心 → 内容管理 → 合集管理 → 添加合集，填 2.2 的资料。
3. 进入合集 → 添加视频 → 勾选本片（一次最多 50 条）→ 排序填 1 → 保存。

> 顺序不能反：合集只收**已过审的单 P 稿件**；账号名下还没有过审稿件时，先发本片再建集最稳。

## 3. 置顶评论

### 3.1 先看三条硬约束

1. **站外链接在评论区是纯文本，不会变成可点超链接。** B 站可直点的站外入口主要是电商「蓝链」，要实名 + 粉丝量 + 带货权限，与本项目无关。所以这条评论按「一眼看懂 + 长按可复制」设计，不按「点一下就跳」设计；真正好点的位置是简介开头。
2. **应用链接必须整条复制。** 本应用是分享码访问，`?sharecode=AXD6562N6Z` 少一个字符会打开「链接不完整」页（已实测：不带参数访问返回该提示）。所以链接单独占一行，前后不加中文标点、不加书名号。
3. **只置顶 1 条。** 置顶位是注意力，不是公告栏；第二条留给高赞评论或作者补充。

### 3.2 主版（推荐，发布后立刻发）

```
一刀万象，网页里直接玩（免登录、免下载）：
https://foldyssey.app.workbuddy.host/?sharecode=AXD6562N6Z

源码在这儿，欢迎 issue / star：
https://github.com/0xaiio/foldyssey

先玩第 1 关，30 秒能剪出第一张；对不上就点「差在哪」。
```

写法说明：两个链接各自独占一行，手机端折行也不会把参数截断；末行给一个具体动作（第 1 关、30 秒、「差在哪」），比「欢迎体验」有效。

### 3.3 短版（手机一屏放得下）

4. 回复前 3 条评论——早期互动比后面补 100 条有用。
