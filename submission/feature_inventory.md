## 未实现 / 未验证（如实列出）

| 项 | 状态 | 说明 |
|---|---|---|
| 任意斜折（如 45° 对角折） | 未实现 | 需要新的合法分区与可平折性说明 |
| 曲线切口 | 未实现 | 与「一刀 / 折剪」语义冲突；现有切割是直线、折线与多边形（菱形/圆形/叶形镂空都是多边形逼近） |
| 实体可打印模板（含 A4 比例尺、折序校验） | 未实现 | 因此 `manufacturability` 从不写 `verified` |
| 分享链接 / 参数化复现链接 | 未实现 | 作品可用 SVG 导出替代 |
| AI 图案曲线花瓣 | 未实现 | 直线/折线切割的固有上限，已用八瓣、锯齿、成圈镂空逼近民间观感 |
| 服务端 AI 配额计量 | 未实现 | 只在客户端限流（5 秒 / 次、每会话 12 次），可被绕过 |
| 真机 iOS / Android 触控回归 | 未验证 | 仅 390×844 视口 + Chromium 内核 |
| Firefox / Safari 实测 | 未验证 | 仅 Edge(Chromium) |
| 浏览器内下载落盘的自动化校验 | 未验证 | 导出函数已有单元测试 |

## 能力边界（对用户可见的承诺）

1. 一刀挑战中**严格只有一条直线**。
2. 工坊的多切口是自由创作，标注为「数字图案」，不是经核验的实体方案。
3. 折叠动画端点精确，中间帧是二维示意，不是物理仿真。
4. 所有目标都由标准解正向生成，"有解"是数据性质，不是声明。
